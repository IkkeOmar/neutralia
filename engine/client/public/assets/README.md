# NEUTRALIA glTF assets

Two Meshopt-compressed glTF 2.0 binaries, generated by script. Rebuild with:

```bash
node tools/build-assets.mjs
node tools/verify-assets.mjs   # 16 assertions, exit 0 on success
```

Both are written to `client/public/assets/` because that is the folder the
bundler copies into the build output. Writing them anywhere else means the
client silently 404s and falls back to primitives.

| File | Size | Triangles | Contents |
|---|---|---|---|
| `map.glb` | 12,236 B | 192 | 16 mesh nodes, one per box in `shared/map.js` |
| `soldier.glb` | 20,800 B | 568 | 1 SkinnedMesh, 19 bones, 2 clips (`idle`, `run`) |
| **total** | **33,036 B (32.3 KiB)** | 760 | well under the 4 MB budget |

## Compression

`EXT_meshopt_compression` plus `KHR_mesh_quantization`. Meshopt was chosen
over Draco because Draco compresses triangle meshes only and leaves animation
tracks untouched — and in a game whose characters animate, the animation is
often the larger payload.

Quantization shifts vertex positions into `[-1, 1]` and compensates with a
node scale of x32. **When verifying a mesh's real size, measure its
world-space bounding box** (`geometry.boundingBox.clone().applyMatrix4(mesh.matrixWorld)`),
not the local one — the local box is normalised and says nothing about the
actual dimensions.

No textures were generated, so there is no KTX2/ETC1S stage. Vertex colours
(`COLOR_0`) carry the palette instead.

## Determinism

The build writes glTF JSON and a `.bin` directly rather than going through
`GLTFExporter`, which gives full control over `JOINTS_0`, `WEIGHTS_0`,
`inverseBindMatrices` and the animation channels — and guarantees the same
bytes every run. Floats are rounded to 6 decimals and every loop is ordered.
